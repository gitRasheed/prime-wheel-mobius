(a) D3b/D3c strictly. The proposal's own framing hides how degenerate the situation is. It is not that "the pin transfers the target losslessly"; it is that the pin has only three terms and they are algebraically dependent — M(A)^2 = 2*S_A(A^2) - M2(A^2) — so "the single signed combination J" is not a joint object built from two things, it is the target with two extra symbols written next to it. Now the deferred leverage. The averaged intermediate is sum_{A<=T} M(A)^2 << T^{2+eps}. Because M is a step function constant on unit intervals, this is int_T^{2T} M(t)^2 dt << T^{2+eps}, and moment-a's certified calibration applies verbatim: |int_T^{2T} M(t)t^{-s-1}dt| <= (int M^2)^{1/2}(int t^{-2sigma-2})^{1/2} << T^{1/2+eps/2-sigma}, which sums dyadically for sigma > 1/2 + eps/2, continuing 1/(s*zeta(s)) past the critical line — RH. It is not weaker. It is RH. There is therefore no intermediate deliverable anywhere in this proposal: pointwise J = RH, averaged J = RH, M2 alone = RH, S_A alone = RH.

## reasoning
The proposal has two separable parts and they get opposite verdicts.

PART 1 — the identity. It is correct. PART 2 — the mechanism. This is where it dies, and it dies on the proposal's own admission plus one classical fact the proposal does not know.

The proposal concedes (guardrail:section_j, honest_weakness 2) that the pin is certified relocation-neutral: J(A) ≡ M(A)^2 as an identity, so the identity alone transfers the target with the exponent preserved in both directions. The averaged object is Σ_A M(A)^2. And Σ_{A<=T} M(A)^2 ≪ T^{2+ε} is RH-equivalent. Forward is trivial from M ≪ x^{1/2+ε}. The converse is elementary and standard: if ∫_1^X M(t)^2 dt ≪ X^{2+ε} then dyadic Cauchy–Schwarz gives ∫_{2^k}^{2^{k+1}} |M(t)| t^{-σ-1} dt ≪ 2^{-k(σ+1)} · 2^{k/2} · 2^{k(1+ε/2)} = 2^{k(1/2-σ+ε/2)}, summable for every σ > 1/2, so F(s) = ∫_1^∞ M(t) t^{-s-1} dt converges absolutely and is analytic on Re s > 1/2; since F(s) = 1/(s ζ(s)) for Re s > 1, ζ has no zeros with Re s > 1/2. This is the classical mean-square Mertens criterion (Littlewood/Titchmarsh-type). So the "averaged intermediate" is not an intermediate at all — it is RH in a different coordinate.
