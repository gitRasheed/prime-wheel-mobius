## Target (one PR, branch pr/degree-one-criterion)

   stranded #362 merge = snapshot copy) into `RHLean/Analysis/` proper.
2. Optionally promote `ThreeSlotDegreeOneSynthesis.lean` likewise (deps all

3. New module `RHLean/Analysis/ThreeSlotDegreeOneCriterion.lean`:
   - `ThreeSlotDegreeOneEnergyBoundedStatement : Prop` — the route doc's
     exact skeleton: ∀ ε>0, ∃ C≥0, ∀ K,
     ‖((threeSlotWa K + threeSlotWb K + threeSlotWc K : ℤ) : ℂ)‖^2
       ≤ C · (K+1)^(1+ε).
   - Endpoint transfer in analytic form:
     ‖mertensSummatory X − mertensSummatory (4·(X/4))‖ ≤ 3, from record
     038's integer lemma `abs_moebiusPrefix_sub_fourCell_le` plus casts.
   - Forward: the statement implies
     `SqrtWheelRecoveredEnergyBoundedStatement` (constants: C ↦ 2C+18 via
     (a+3)² ≤ 2a²+18; monotone rpow in the base; (X+1)^(1+ε) ≥ 1).
   - Converse: the recovered-wheel criterion implies the three-slot
     statement (evaluate at X = 4K; constant C·4^(1+ε) via
     4K+1 ≤ 4(K+1) and mul_rpow). Hence an iff, stronger than the assigned
     implication.
   - `riemannHypothesis_of_threeSlotDegreeOneEnergy` chaining through
     `riemannHypothesis_of_sqrtWheelRecoveredEnergy`.
