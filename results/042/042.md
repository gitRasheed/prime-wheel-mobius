## Target (branch pr/fiber-pin, new module RHLean/Analysis/PrimeSieveFiniteDifferencePin.lean)

1. `primeSieveCanonicalPin_divisor_backward_stable`: for `t ≤ y`, `0 < d`,
   `(pin y / d) / (y+1) = ((pin y − t) / d) / (y+1)` — via
   `Nat.div_div_eq_div_mul` and the existing pin lemmas. This is the fact
   that makes each fiber step legal: the sharp affine modulus
   (`primeSieveMoebiusDiscrepancySum_increment_norm_le_affine`) carries a
   support-stability hypothesis, so the general window theorem
   (`finiteDifferenceOperator_increment_norm_le_activeOn`) CANNOT be applied
   with a global modulus; the proof must apply the sharp modulus once per
   fiber, at aligned positions only.
2. Fiberwise modulus at the pin (per divisor `d` of the primorial):
   `‖S(y, pin/d) − S(y, (pin−t)/d)‖ ≤ A_y·δ_d + B_y` on moving fibers,
   `0` on frozen ones, with `A_y = primeSieveAffineSlope y y`,
   `B_y = primeSieveAffineIntercept y y`, `δ_d` the fiber displacement.
3. Headline (Codex record-039 spec, statement fixed at design time):
   `primeSieveFiniteDifference_backward_increment_norm_le_active`:
   `‖D_S S(y,·)(pin y) − D_S S(y,·)(pin y − t)‖ ≤
    A_y·t·Π_{p∈S}(1+1/p) + (A_y+B_y)·N_active`,
   for genuine prime sets `S`, `1 ≤ y`, `t ≤ y`, where `N_active` is the
   moving-fiber count. Sum of fiber displacements bounded via
   `floor_add_div_sub_le` + `sum_inv_divisors_primorial`.
4. Worst-case audit corollary only: `N_active ≤ 2^{|S|}` via
   `card_divisors_primorial`; documented as bookkeeping, analytically
   useless for `S = primesUpTo y` (per the record-039 verdict, no growing-
   wheel claim anywhere).
